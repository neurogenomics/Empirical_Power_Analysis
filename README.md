# Empirical Power Analysis for Sex-Biased Differential Expression in Brain snRNA-seq

![Study overview](Figure1_Diagram.png)

Code and paper-ready figures accompanying:

> **Current Single-Cell Study Designs Are Systematically Underpowered for Small-Effect Genes: Empirical Power Analysis Across 22 Million Detection Outcomes**
> Chris Crampton, Salman Fawad, Hiru Dash, Nathan Skene

## Overview

This repository contains the complete analysis pipeline used to empirically measure detection power for pseudobulk differential expression in human brain single-nucleus RNA-seq. The PsychAD cohort (≈1,200 donors) is systematically downsampled across a two-dimensional grid of donor count × cell count (and separately, donor count × reads per cell), producing over 22 million per-gene detection outcomes. Sex-biased expression is used as a reproducible case-control variable with a biologically grounded ground truth.

Outputs include:

- Continuous recall and precision surfaces across the experimental design space for three glial cell types (astrocytes, microglia, oligodendrocytes).
- Fitted logistic-regression power curves (`power_equation_coefficients.csv`) and a lookup table (`power_lookup_table.csv`).
- A standalone `predict_power.R` function for predicting detection probability from arbitrary experimental designs and gene characteristics.
- Cross-dataset validation against four independent snRNA-seq cohorts (Allen/SEA-AD, DeJager/ROSMAP, Rexach, Johansen) and a GTEx v8 bulk RNA-seq reference.

## Scientific scope

- **Primary dataset:** PsychAD (Fullard et al., 2025), filtered to 1,293 astrocyte donors, 1,214 microglia donors, and 1,303 oligodendrocyte donors. See `Datalink/Dataset_Statistics_Table/Supplementary_Table_1_Dataset_Characteristics.csv`.
- **Validation datasets:** SEA-AD (Allen), ROSMAP (DeJager), Rexach, Johansen — used for cross-dataset IoU, sign, and LFC agreement.
- **Bulk reference:** GTEx v8 (838 donors across 44 tissues) for external LFC calibration.
- **Case-control variable:** Sex. Chosen because (i) sex is close to 50:50 in all brain cohorts; (ii) a well-characterised set of sex-biased genes (principally on the sex chromosomes) provides a reproducible ground truth; (iii) sex-biased DE generalises across independent cohorts.
- **DE method:** DESeq2 with pseudobulk aggregation and apeglm shrinkage.
- **Power model:** Logistic regression on log-transformed donors, cells per donor, reads per cell, |LFC|, base mean, and dispersion.

## Key findings

1. **Small-effect genes (|LFC| 1–2) never exceeded 80% pooled recall** across the entire experimental space, including 600 donors with all available cells. The tiny-effect bin (|LFC| 0.2–1.0) never exceeded 43% recall.
2. **Large-effect genes (|LFC| > 3)** reached 80% recall with as few as 10–15 donors, provided ≥750 cells per donor were available.
3. **The apparent cell-type power hierarchy (microglia > astrocytes > oligodendrocytes) is an artefact of DESeq2 independent filtering.** Depth equalisation (downsampling astrocytes to microglia-equivalent reads per cell) inverts the hierarchy, showing that cellular yield per donor is more determinative than per-cell sequencing depth. Oligodendrocytes, with 96% of genes testable after independent filtering, provide the most conservative power estimates.
4. **Sex-biased DE is reproducible across independent cohorts.** Universe-controlled IoU values between PsychAD and four external datasets range from 0.60 to 0.92, approaching the 0.65–0.87 split-half ceiling.

## Reproducing the analysis

### Requirements

- **R** ≥ 4.2

**Bioconductor packages:**
`DESeq2`, `apeglm`, `SingleCellExperiment`, `SummarizedExperiment`,
`BiocParallel`, `biomaRt`, `AnnotationDbi`, `org.Hs.eg.db`, `rhdf5`,
`zellkonverter`.

**CRAN packages:**
`here`, `qs`, `Matrix`, `dplyr`, `tidyr`, `stringr`, `ggplot2`, `patchwork`,
`scales`, `RColorBrewer`, `viridis`, `UpSetR`, `ggnewscale`, `ggrepel`,
`pheatmap`, `cowplot`, `shadowtext`, `akima`, `data.table`, `future`,
`future.apply`, `reticulate`, `testthat`, `knitr`.

Install everything in two calls:

```r
install.packages(c(
  "here", "qs", "Matrix", "dplyr", "tidyr", "stringr", "ggplot2", "patchwork",
  "scales", "RColorBrewer", "viridis", "UpSetR", "ggnewscale", "ggrepel",
  "pheatmap", "cowplot", "shadowtext", "akima", "data.table", "future",
  "future.apply", "reticulate", "testthat", "knitr", "BiocManager"
))
BiocManager::install(c(
  "DESeq2", "apeglm", "SingleCellExperiment", "SummarizedExperiment",
  "BiocParallel", "biomaRt", "AnnotationDbi", "org.Hs.eg.db", "rhdf5",
  "zellkonverter"
))
```

Individual pipelines use only subsets of this list; each
`R/<pipeline>/config.R` loads the packages it actually needs.

### Resolving the project root

Each pipeline's `config.R` detects the project root automatically via `here::here()`. You can override this with the `POWER_ANALYSIS_ROOT` environment variable, which is useful when running on clusters where the working directory is not the repo root:

```bash
export POWER_ANALYSIS_ROOT=/path/to/this/repo
```

### Data prerequisites

This repository includes **final figures and paper source data only** — the raw input data (h5ad / h5Seurat files and donor shards) is not distributed here owing to its size and dataset-specific access terms. To reproduce the analysis from scratch, follow `R/sharding/` to regenerate donor shards from the public dataset sources listed in `Datalink/Dataset_Statistics_Table/Supplementary_Table_1_Dataset_Characteristics.csv` and place the results under `Datalink/Shards/{CellType}/{Dataset}/`.

Each pipeline's `README.md` documents its expected inputs (normally under `Datalink/` subdirectories) and its outputs.

### Running a pipeline

Every pipeline contains a `run_pipeline.R` master runner. Example:

```bash
Rscript R/cartesian_downsampling/run_pipeline.R            # Run all steps
Rscript R/cartesian_downsampling/run_pipeline.R 3,7 16     # Run steps 3 and 7 on 16 cores
```

Individual steps (e.g. `01_Generate_Ground_Truth.R`, `02_Run_Downsampling_Grid.R`) can also be invoked directly.

## Using the fitted power models

The `predict_power()` function accepts an experimental design and returns a predicted detection probability under the fitted cell-type model:

```r
source("Datalink/Power_Curve_Fitting/Exports/predict_power.R")

predict_power(
  n_donors       = 100,
  n_cells        = 500,
  reads_per_cell = 6000,
  abs_lfc        = 3.0,
  basemean       = 100,
  dispersion     = 0.5,
  cell_type      = "Oligo"
)
#> ≈ 0.94
```

Exhaustive predictions for a broad grid of design parameters and gene characteristics are pre-computed in `Datalink/Power_Curve_Fitting/Exports/power_lookup_table.csv`.
